# Stardew Fishing: Individual Treasure

A Minecraft mod that lets you customise which fish have which treasure reward for Stardew Fishing.
Tested with:
Minecraft 1.21.1 - NeoForge 21.1.259 - Java 21 - Stardew Fishing 3.7

---

## Compatibility
Stardew Fishing: Individual Treasure has in-built compatibility with these mods:
- Additional Attributes (Fishing Luck attribute)
